# Relay Pipeline v0.1

Architect → Developer → Reviewer → QA → Release Gate

## Isolation rule

Следующая роль получает spec/task, AC, diff/evidence, assumptions, unresolved questions и релевантные context refs. Она не получает полный reasoning/историю предыдущей роли.

## Goal

Снизить confirmation bias, контекстный шум, token duplication и повторное чтение нерелевантной истории.
