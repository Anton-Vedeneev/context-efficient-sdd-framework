# OpenSpec Adapter

Status: skeleton.

Используется, если `workflow.adapter: openspec`.

- OpenSpec — единственный выбранный workflow.
- Framework не должен параллельно создавать Superpowers-структуру.
- Core concepts: requirement, spec, plan, task, decision, AC, implementation, review.
- Adapter отвечает только за отображение этих понятий в OpenSpec artifacts/commands.
