# Metrics

## Efficiency
- tokens / completed task
- iterations / accepted task
- time-to-accepted-task

## Quality
- first-pass acceptance rate
- escaped defects
- reopened tasks
- AC coverage
- verification failures

## Context quality
- assumptions created
- assumptions invalidated
- missing requirements discovered after implementation
- context escalations
- contradictions discovered
